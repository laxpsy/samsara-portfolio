## dev

```bash
bun install
bun run dev
```

## keybindings

| Key | Action |
|-----|--------|
| `?` | show keybindings |
| `q` / `Esc` | close keybindings |
| `b` | enter BLOG mode (on `/`) |
| `j`/`k` | select entry (BLOG mode) |
| `h`/`l` | paginate (BLOG mode) / swipe on mobile |
| `Enter` | open entry (BLOG mode) |
| `p` | go to /portfolio |
| `n` | go to /now |
| `Esc` | go home / exit BLOG mode |
